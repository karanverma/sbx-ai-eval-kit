# AI Evaluation Workflow

This sandbox is configured for AI evaluation workflows.

When performing evaluations:

1. Record outputs and observations.
2. Compare baseline and candidate systems.
3. Document failures and unexpected behavior.
4. Report limitations and uncertainty.
5. Avoid drawing conclusions without supporting evidence.

Focus on reproducibility, transparency, and clear documentation.

When possible:

* Save evaluation artifacts.
* Record evaluation settings and assumptions.
* Highlight edge cases and failure modes.
* Distinguish observations from conclusions.
