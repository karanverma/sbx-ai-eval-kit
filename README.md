# SBX AI Evaluation Kit

A Docker Sandbox (SBX) Mixin Kit designed for AI evaluation workflows.

## Motivation

As AI agents become more capable and autonomous, evaluation workflows need to be reproducible, isolated, and easy to share. Many evaluation environments are configured manually, making it difficult to reproduce results consistently across projects and teams.

This project explores how Docker Sandbox Kits can provide a reusable environment for benchmarking, testing, and evaluating AI systems.

## Goals

- Reproducible AI evaluation environments
- Evaluation-focused agent instructions
- Controlled network access
- Repeatable benchmark workflows
- Alignment with AI safety and governance practices

## Planned Features

- SBX Mixin Kit
- AGENTS.md guidance
- Evaluation workflow templates
- Example benchmark configurations
