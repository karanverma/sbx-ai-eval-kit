# Roadmap

## Vision

Create a reusable Docker Sandbox (SBX) Mixin Kit that helps developers, researchers, and evaluation teams run AI evaluation workflows in isolated and reproducible environments.


## Version 0.1 (Current)

Project foundation and design phase.

### Completed

* Project README
* Design documentation
* AGENTS.md evaluation guidance
* Initial SBX mixin specification
* Sample evaluation workflow

### Goals

* Define project scope
* Gather community feedback
* Explore SBX kit design patterns


## Version 0.2

Evaluation workflow improvements.

### Planned

* Example benchmark configurations
* Improved agent guidance
* Evaluation templates
* Better documentation and usage examples

### Success Criteria

* Community review of workflow design
* Feedback from Docker Captains
* Identification of common evaluation use cases


## Version 0.5

Reusable evaluation environments.

### Planned

* Lightweight evaluation tooling
* Reproducible workflow examples
* Structured evaluation artifacts
* Additional sample projects

### Success Criteria

* End-to-end example workflow
* Demonstration of reproducibility benefits
* Initial contributor feedback


## Version 1.0

Stable SBX AI Evaluation Kit.

### Planned

* Mature evaluation workflow support
* Clear documentation
* Community-tested examples
* Integration guidance for common evaluation scenarios

### Success Criteria

* Public release
* Community adoption
* Contributions and feedback from SBX users
